# DSB

基于 **ESP32** 的温度采集小型 IoT（LOT）系统，使用 **DS18B20** 温度传感器采集数据，并将数据上报到**华为云**进行实时观测与管理。

## 项目简介

本项目实现了一个从“设备侧采集”到“云端展示”的完整流程：

- 设备端：ESP32 周期性读取 DS18B20 温度数据
- 网络通信：通过 ESP32 联网后将数据上传至华为云
- 云平台：在华为云控制台查看温度变化与设备状态

适合作为 ESP32 + 传感器 + 云平台接入的入门实践项目。

## 硬件组成

- ESP32 开发板
- DS18B20 温度传感器
- 4.7kΩ 上拉电阻（DS18B20 数据线常用）
- USB 供电与下载线

## 功能说明

- 温度实时采集
- 设备联网与数据上报
- 华为云端可视化观测

## 适用场景

- 环境温度监测
- 学习 IoT 设备上云流程
- 课程设计 / 小型实验项目
